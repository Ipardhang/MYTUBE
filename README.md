# MyTube

MyTube is the training YouTube clone extended for the Elevance Skills internship requirements. It retains the provided Next.js, Express, and MongoDB project structure and adds internship features to that codebase.

## Technology

- Next.js 15, React 19, TypeScript
- Express 5 and MongoDB/Mongoose
- Firebase Authentication
- Responsive web interface

## Internship feature areas

- Multilingual comments with moderation, reports, voting, replies, and sorting
- Plan based downloads and download history
- Free, Bronze, Silver, and Gold subscription dashboard with Razorpay test mode hooks
- Login theme preferences, trusted-device security, and session history
- Custom HTML5 player controls and watch progress
- Video call rooms with browser media controls

## Run locally

See `yourtube/README.md` and `server/README.md` for setup instructions and required environment variables. Never commit production credentials or payment secrets.

This repository continues the training project supplied at https://github.com/BitHeadmr/you_tube2.0. The original repository is not modified.
